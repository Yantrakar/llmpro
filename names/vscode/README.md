# llmpro

llmpro is not released yet. This package only holds the name.

It will keep the skills, memory and chat history of your AI coding tools in one place, shared
across tools and machines, and check that no secret or wrong git identity leaks out of them.

From Yantrakar, the makers of [gitpro](https://gitpro.dev). News at [yantrakar.com](https://yantrakar.com).
